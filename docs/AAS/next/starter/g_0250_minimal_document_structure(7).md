# G0250 Minimal Document Structure（強化ミニマル版）

SCAI 再開時に文書構造の揺らぎを完全に排除するための **最小かつ強固な構造規範**。

---

## 1. Front Matter（FM）

文書最上部に必須。CreativeWork 形式で統一。

必須キー：

```yaml
schema: "https://schema.org/CreativeWork"
type: CreativeWork
identifier: "Gxxxx または Pxxxx"
name: "文書名（日本語）"
version: "1.0.0"
inLanguage: "ja"
datePublished: "YYYY-MM-DD"
description: "文書概要"
```

---

## 2. TOC（Table of Contents）

FM の直後に配置。**原則必須**。

* ただし H2 が 1 つのみの場合は省略可。
* 自動生成を前提とし、手動編集は禁止。

---

## 3. 文書タイトル（H1）

FM → TOC の次に配置。識別子や番号を含めない。

```
# 文書タイトル
```

---

## 4. 見出し構造（階層）

* **H1**：文書タイトル（1回のみ）
* **H2**：章
* **H3**：小区分（最大階層）
* **H4 以降は禁止**

章構成テンプレ：

```
# タイトル
## 1. Purpose
## 2. Scope
## 3. Content
### 3.1 ...
### 3.2 ...
## 4. Notes
```

---

## 5. 空行（Blank Line）ルール

* 見出しの前後には 1 行空ける（MUST）
* 箇条書きの前後に空行を入れない（SHOULD）
* 段落間は 1 行空ける

---

## 6. Markdown 規範（Minimal GFM）

### MUST

* GFM に準拠
* HTML タグ禁止（div / span / br / img / table / comment 等）
* 箇条書きは `-` のみ
* 番号付きリストは `1.` のみ（自動昇順に任せる）
* コードブロックは「``` + 言語名」必須
* 水平線は `---` のみ
* 表（table）禁止（B層で扱う）
* インラインコードは必要最小限に限定
* 強調は **太字（** **）のみ** 使用。斜体禁止。
* 引用（>）は 1 階層のみ使用可
* AI は文書構造を勝手に再構成してはならない
* 章番号を勝手に振り直してはならない

### SHOULD

* 箇条書きは 2 階層まで
* 行末の空白を作らない
* 括弧は日本語括弧（（））に統一。英語括弧は固有名詞のみ。

### 包括禁止ルール

以下の記法はすべて禁止：

* 脚注（[^1]）
* 定義リスト（:）
* Markdown 拡張（Mermaid、拡張構文全般）
* 画像埋め込み（![]()）
* HTML コメント（<!-- -->）
* 数式記法（$ $ / $$ $$）

---

## 7. ファイル構造の固定順序

1. FM
2. TOC
3. タイトル
4. 本文（H2 → H3）
5. 終端（空行なし）

ChatGPT はこの順序を変更してはならない。

---

## 8. ファイル要件

* UTF-8（BOM なし）
* 改行コード：LF
* ファイル名は ASCII 安全文字符号のみ
* 拡張子 `.md`
* 章番号は手動管理し、AI が自動修正しない

---

## 9. 禁止事項まとめ

* HTML 埋め込み
* 表の使用
* GFM 非準拠の記法
* 言語名なしコードブロック
* 4階層以上の見出し
* 意図しない自動再構成
* 推測による構造生成

---

（End of Enhanced G0250 Minimal Version）
