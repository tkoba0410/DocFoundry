# G0400 – Framework Tree（SCAI フレームワーク｜正式呼称：スカイ）

> **SCAI補足（Framework Tree 注釈）**
>
> G0400 は SCAI（Structured Cooperative AI Framework／スカイ）における “体系の公式インデックス” であり、A/B/C/D の階層と分野ID（01〜99）、手法ID（01〜99）を構造として定義する重要文書である。ここに示される番号体系は、人間とAIが共通の構造基盤の上で協働するための参照の要であり、SCAI 全体の一貫性と追跡可能性を支える。（体系目録・純粋インデックス版）

## 1. 目的

SCAI の **全成果物を番号体系に基づいて一覧化**した公式インデックスである。
本書は説明ではなく **“構造の目録” に専念**し、詳細な解説は G0300（Overview）、番号体系の規則は G0050 に委譲する。

## 3. B層（分野フレームワーク） – Gxx00

**上2桁：分野ID（01〜99） / 下2桁：00 固定**

### B層 分野ID一覧（表形式）

| ID    | 分野名          | 説明            |
| ----- | ------------ | ------------- |
| 01    | Document     | 文書構造・運用       |
| 02    | YAML / Spec  | 構造化仕様・チェックリスト |
| 03    | SCD          | 開発プロセス統合モデル   |
| 04    | Coding       | コーディング規範・レビュー |
| 05    | AI Prompt    | AI指示・構造化プロンプト |
| 06    | OPS          | 運用・Runbook・監視 |
| 07    | Testing      | テスト・品質モデル     |
| 08    | Security     | セキュリティ基準      |
| 09    | Architecture | ADR・構造設計      |
| 10    | Governance   | ポリシー・管理体系     |
| 11〜99 | Reserved     | 拡張用           |

## 7. 本書の役割（インデックスとしての責務）
