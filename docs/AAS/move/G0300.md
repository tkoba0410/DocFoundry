# G0300 – Framework Overview（SCAI フレームワーク｜正式呼称：スカイ）

> **SCAI 追加説明（Overview 拡張）**
>
> SCAI（Structured Cooperative AI Framework／スカイ）は、人間とAIが対等に協働し、構造化された文書を共通の基盤として扱うための総合フレームワークである。G0300（Overview）は、SCAI 全体を俯瞰するための“地図”として機能し、理念（G0000）・原則（G0100）・構造規範（G0200）・体系目録（G0400）を横断的に理解するための位置づけを提供する。
>
> SCAI における A/B/C/D の4層構造は、単なる文書分類ではなく、人間とAIが誤解なく協働するための構造的役割分担である。A層は共通の思想と原則を定め、B層は分野単位の構造ルールを定義し、C層は具体的な手法を提供し、D層はプロジェクト適用を担う。この“上位→下位への一方向構造”こそが、SCAI の一貫性と可読性の核心である。

> **SCAI（Structured Cooperative AI Framework）とは？**
>
> SCAI（スカイ）は、人間とAIが上下関係なく対等に協働し、構造化された文書と共通基盤を通じて作業を進めるための体系である。A層はその理念・原則・構造規範を定義し、全体の背骨となる。（全体構造の地図・簡素化版）

## 1. 目的（Purpose）

G0300 は SCAI の **全体像を俯瞰するための地図** である。
詳細な規範（G0200）や具体的な体系（G0400）とは異なり、
**“構造をどう理解すればよいか” を最短距離で示す** ことを目的とする。

---

## 2. Framework の4層構造（A/B/C/D）

SCAI は以下の 4 つの層によって構成される。

### 2.1 A層（理念・原則・抽象規範）

* Foundation（G0000）
* Core Principles（G0100）
* Meta Rules（G0200）
* Overview（本書）
* Framework Tree（G0400）

**役割：** WHY（存在理由）・WHAT（原則）・HOW（抽象規範）を定義する最上位層。

### 2.2 B層（分野フレームワーク：Gxx00）

* 分野ID（01〜99）で管理される中間フレームワーク層
* 分野横断の一貫性と役割の切り分けを担う

例：01 Document / 02 YAML / 03 SCD / 04 Coding …

### 2.3 C層（手法・テンプレート：Gxx01〜99）

* B層に属する分野ごとの具体的な手法群
* **Gxx00 → Gxx01〜99** の構造で分野と一貫して紐づく

### 2.4 D層（プロジェクト：Pxxxx）

* 標準（G系）とは独立したプロジェクト成果物領域

---

## 3. 番号体系と層の関係（超要約）

番号体系は SCAI の構造そのものを表す。

```
A層：G00xx    （理念・原則）
B層：Gxx00    （分野フレームワーク）
C層：Gxx01〜99（手法）
D層：Pxxxx    （プロジェクト）
```

**ポイント：**
番号だけで階層が完全にわかるよう設計されている。

## 5. A→B→C→D の基本構造（最重要図）

SCAI を理解する最短経路は以下の一本の流れである。

```
A（理念・原則）
   ↓ 翻訳
B（分野構造）
   ↓ 具現化
C（手法）
   ↓ 適用
D（プロジェクト）
```

この順方向のみを許可し、逆流（C→A）や混濁を防ぐことで、 体系全体の一貫性と可読性を保証する。

---

## 6. 本書の位置付け

G0300 は以下の間をつなぐ「理解の橋渡し文書」である：

* G0200：抽象規範（Meta Rules）
* G0400：体系目録（Framework Tree）

**G0200 が “構造のルール” を説明し、**
**G0400 が “具体的な一覧” を示し、**
**G0300 はその “地図” を提供する。**

```text

                \                  /

        │ G0300 Overview（全体地図）          │

        ┌──────────────── B層 ────────────────┐
```
